# Bible-Syntax
All praise be to the Lord Jesus! There is now clause, phrase, and syntactical analysis for E-Sword! This content was designed for the iOS versions of E-Sword.

This content was created by using Python scripts to pull data from publicy available online datasets and turn them into a functional tool to understand meanings and nuances in the Bible.

The Old Testmament data was taken from the text-fabric representation of the Hebrew Bible Database, [BHSA](https://github.com/ETCBC/bhsa), containing the text of the Hebrew Bible augmented with linguistic annotations compiled by the Eep Talstra Centre for Bible and Computer, VU University Amsterdam.

The Strong's numbers were keyed using [BHS-Strong-no](https://github.com/eliranwong/BHS-Strong-no) by Eliran Wong.

The New Testament data comes from The [Nestle 1904 GNT](https://github.com/CenterBLC/N1904), which features the ability to present the Greek text as a syntax tree using constituency grammar, reflecting the hierarchical arrangement of grammatical elements within the sentence.

This linguistic data was taken from MACULA Greek Linguistic Datasets, available at:
https://github.com/Clear-Bible/macula-greek/

This project would not be possible without [Text-Fabric](https://github.com/annotation/text-fabric), which provides the Python framework to load, query, and traverse both datasets. It provides all of the APIs required free of charge.
